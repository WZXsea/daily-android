# 日常 Android 安装包

本仓库提供“日常”Android 安装包下载；发布页仅包含 APK 和 SHA-256 校验文件。源码仓库未公开。

## 下载与安装

1. 打开[最新版本](https://github.com/WZXsea/daily-android/releases/latest)，下载 `daily-0.1.1.apk`。
2. 安装后输入服务器地址 `https://daily.wzx2002.icu`，以及从自己的网页版账号创建的个人访问令牌（PAT）。安装包不内置令牌。
3. 可下载同一版本的 `SHA256SUMS` 校验 APK。0.1.1 的 SHA-256 为 `d73f5b687bcc58e10571fc0cb962846941be9e242a4a0a0df1546f33997144fe`。

包名：`icu.wzx2002.daily`。目标设备：K80 Pro / Android 14。Android 14 模拟器已通过正式服务器联机测试；K80 Pro 真机体验仍需验证。

本应用基于 [Memos](https://github.com/usememos/memos) 修改。原项目的 MIT 许可见 [LICENSE](LICENSE)。
