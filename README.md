# 日常 Android 安装包

本仓库提供“日常”Android 安装包与 SHA-256 校验文件，源码保存在私有仓库。

## 下载与安装

1. 打开[最新版本](https://github.com/WZXsea/daily-android/releases/latest)，下载 `daily-0.1.5.apk`。同一签名支持覆盖安装已有版本。
2. 安装后输入服务器地址 `https://daily.wzx2002.icu`，以及从自己的网页版账号创建的个人访问令牌（PAT）。令牌由你在首次连接时输入，随后保存在手机受保护存储。
3. 下载同一版本的 `SHA256SUMS` 校验 APK。

## 0.1.5 更新

- 编辑默认开启实时预览：加粗即时显示并隐藏星号，支持斜体、删除线、行内代码和标题；“更多”菜单可切换源码模式并记住选择。
- 快捷编辑从打开时固定贴顶，输入法和附件菜单切换时保持顶部位置；弹窗与菜单增加短过渡并适配系统减弱动态效果。
- 顶栏搜索支持多个关键词、标签和当前／全部／指定笔记本范围。
- 新增 AI 助手，支持自定义兼容 API 服务地址、密钥和模型。可生成、修订、润色指定内容，或对个人笔记总结、查找和整理。结果提供来源与应用预览；连接及调用由服务端统一提供。

使用 AI 时，在星光图标入口的“API 设置”保存自己的连接。发起调用后，服务器把本次指定文本或所选笔记发送给该服务。库检索使用有限候选和上下文，结果会提示覆盖范围，可通过笔记本、标签与关键词分批聚焦。

此前版本已包含桌面快捷记录小部件、在线状态、底部绿色“＋”入口、Markdown/公式阅读兼容和表格一键复制。

包名：`icu.wzx2002.daily`。目标设备：K80 Pro / Android 14。构建验证包括前端回归、Android 单元测试、Lint、签名与 Android 14 模拟器启动及存储测试。输入法过渡与字体观感可在 K80 Pro 安装后继续验收。

本应用基于 [Memos](https://github.com/usememos/memos) 修改。原项目的 MIT 许可见 [LICENSE](LICENSE)。
