# 日常 Android 安装包

本仓库提供“日常”Android 安装包与 SHA-256 校验文件，源码保存在私有仓库。

## 下载与安装

1. 打开[最新版本](https://github.com/WZXsea/daily-android/releases/latest)，下载 `daily-0.1.10.apk`。同一签名支持覆盖安装已有版本。
2. 安装后输入服务器地址 `https://daily.wzx2002.icu`，以及从自己的网页版账号创建的个人访问令牌（PAT）。令牌由你在首次连接时输入，随后保存在手机受保护存储。
3. 下载同一版本的 `SHA256SUMS` 校验 APK。

## 0.1.10 更新

- 快捷新建先将文字及附件存入手机，再关闭编辑器，弱网和断网时保持顺畅。
- 由安卓系统后台任务在联网后同步；首页显示本机条目、等待同步、同步中及重试入口。
- 固定资源 ID 配合回查处理提交响应丢失，避免重试产生重复条目；附件上传支持恢复进度。
- 待同步记录独立保存并按连接隔离，重新打开应用后恢复。现有条目修改及评论继续采用联网保存。

后台同步遵循 Android 的网络与任务调度。本版沿用原签名，可在应用内检查更新后覆盖安装。

## 0.1.9 更新

- 安卓 AI 对话可在 API 设置中选择服务器上已保存的 magpie 服务商，一次导入本机，无需再次输入 API 密钥。
- 默认对话模型为 `workbuddy/deepseek-v4.1-flash`；导入前可修改。
- 密钥通过设备临时密钥加密交付，保存在 Android Keystore；后续模型请求从手机直连服务商。
- 服务端已先更新配套接口，magpie 的 TLS 连接、目标模型、流式响应和工具调用经实际验证。

0.1.8 已具备应用内更新入口，可直接检查并安装本版。

## 0.1.8 更新

- Android 应用会每日检查新版本，头像菜单可随时手动检查。
- 在应用内查看更新说明、下载安装包并查看进度；支持取消、重试和重启后继续安装。
- 下载完成后核对 SHA-256、包名、版本号与原签名，再由 Android 系统确认安装。首次更新可能需要在系统设置中允许“日常”安装应用。

首次需要覆盖安装 `daily-0.1.8.apk`，后续版本可在应用内检查并安装。

## 0.1.7 更新

- 修复 AI 回复包含标签或待办清单时，出现 `useMemoViewContext` 异常并进入错误页的问题。
- AI 回复使用独立展示模式，流式输出及历史会话均可显示标签和清单，保留加粗、公式、代码块与表格复制。
- 保持笔记卡片的标签筛选与任务勾选功能；覆盖升级后继续使用已有本机设置和会话。

## 0.1.6 更新

- Pi Agent 内置 APK，提供连续对话、流式回复和工具调用，可按要求查找、读取、新建、编辑个人笔记。
- 模型 API 地址、模型名称、密钥和会话各端独立保存。Android 密钥使用 Keystore 加密，模型请求从手机直接连接配置的服务。
- AI 修改先保存到本端，再同步到 Memos。新增本地同步区，支持预览、复制、重试与冲突处理；另一端修改过同一笔记时保留本地内容。
- 停止操作中止模型连接及后续工具；重新打开聊天可继续查看当前任务，进程重启后保留已保存结果。

在星光入口的齿轮设置中配置支持工具调用的 OpenAI Chat Completions 兼容 API。网页版使用浏览器内的同一 Pi 内核，并保存自己的连接配置；网页直连 API 需服务商支持对应来源的 CORS。笔记编辑结果经 Memos 同步到其他端。

本地笔记副本支持在 Memos 暂时不可达时读取已有内容；AI 生成需要能够访问配置的模型服务。本地同步区显示缓存覆盖范围和最后刷新时间。

此前版本已包含桌面快捷记录小部件、在线状态、底部绿色“＋”入口、Markdown/公式阅读兼容和表格一键复制。

包名：`icu.wzx2002.daily`。目标设备：K80 Pro / Android 14。构建验证包括前端回归、Android 单元测试、Lint、签名与 Android 14 模拟器启动及存储测试。输入法过渡与字体观感可在 K80 Pro 安装后继续验收。

Agent 核心使用 [Pi SDK](https://github.com/earendil-works/pi)。

本应用基于 [Memos](https://github.com/usememos/memos) 修改。原项目的 MIT 许可见 [LICENSE](LICENSE)。
